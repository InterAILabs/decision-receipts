# Security

Please do not include credentials, private keys, access tokens, production payloads, receipt contents, or other secrets in public issues.

For a security issue in this repository or the related InterAI Risk Oracle service, contact `interailabs@gmail.com` with enough detail to reproduce the problem safely.

This repository consumes documented receipt evidence only. It does not contain signing keys, private signing implementation, account data, hosted decision-engine internals, production stores, billing systems, or operational secrets.
